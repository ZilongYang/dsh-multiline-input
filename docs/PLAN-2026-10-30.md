## 1. 目标与验收标准

**目标**：在现有单行 / 多行切换插件上补齐 0.2.0 的交互能力，不改变 0.1.1 已验收的行为：

1. tab 右侧新增收起按钮，收起后变成输入卡片上沿右对齐的 8px 细线；点击细线恢复 tab；状态按设备持久化；`Cmd/Ctrl+E` 收起后仍生效。
2. 每轮**被 Host 接受**的普通消息文字写入设备侧输入历史（全局、去重、限量、可清空）；`/` 命令、空提交、失败/被拒提交不记录。
3. 输入框内：单行模式 `↑` / `↓`，多行模式 `Shift+↑` / `Shift+↓`，按最近提交顺序循环替换；首次 `↑` 保存当前草稿，`Esc` 或在新条目上再按 `↓` 还原并退出；浏览时 tab 显示「历史 n/m」。
4. 全部逻辑以 DSH 0.2.1-rc.5 的公开契约与 DOM 锚点为准回归；`sending` 相位不拦截、不误记。
5. 单测、语法检查、打包清单全绿；文档与版本号同步。

**验收标准**：

- 收起后输入区高度实际减少（桌面 dock 态约 16px），刷新后保持收起；点击细线恢复；展开态与原 0.1.1 观感一致。
- 收起状态下 `Cmd+E` 仍切换模式（高度变化可见），不报错。
- 提交一条消息后清空输入框，按 `↑` 出现该文字；连续 `↑` 逐条向前，到最旧后回到最新；`↓` 反向；从最新再按 `↓` 或按 `Esc` 还原浏览前草稿。
- 多行模式下 `Shift+↑` / `Shift+↓` 浏览历史，普通 `↑` / `↓` 仍是原生光标移动；单行模式普通 `↑` / `↓` 浏览。
- 菜单打开、输入法组合态、`/` 命令 claim、`adjudicating` / `submitting` / `sending` 相位下，方向键完全交还原有逻辑。
- 断网 / Host 拒绝导致的失败提交不进入历史；之后成功提交的同一文字正常进入。
- 禁用 / 卸载插件后无监听、无样式、无 DOM 残留；历史数据保留，重新启用后可用。
- 0.1.1 的 Enter/Shift+Enter、多行高度、模式持久化、快捷键改绑全部不回归。

## 3. 实现设计

全部改动集中在 `client.js`，不新增构建、不新增 Host 服务、不改 `index.js`。

### 3.1 常量与本地数据结构

新增 `HINT_STORAGE_KEY`（`dsh-multiline-input.hint.v1`，`collapsed` / `expanded`）、`HISTORY_STORAGE_KEY`（`dsh-multiline-input.history.v1`）、`CLEAR_HISTORY_COMMAND_ID`（`multiline-input.clear-history`）、`HISTORY_MAX_ENTRIES=200`、`HISTORY_MAX_TOTAL_CHARS=100000`、`HISTORY_MAX_ENTRY_CHARS=16000`。历史文档形如 `{ "version": 1, "entries": [{ "text", "at" }] }`，读取容错、写入失败降级内存态。

### 3.2 输入历史记录（Host 接受后才落库）

在 `MultiLineHint` 内订阅 `useInput(s => s.phase)`、`useInput(s => s.draft)`、`useSession(s => s.pendingSubmissions)`。`phase === 'sending'` 时把 draft 记为 pendingText；`pendingSubmissions` 出现新 `requestId` 时提交 pendingText。下一次 sending 替换未确认捕获；组件卸载丢弃。记录前清洗：trim 空 / 以 `/` 开头 / 超长跳过；完全相同的文字去重置顶；按 200 条 / 10 万字符淘汰。

### 3.3 ↑ / ↓ 浏览历史

`MultiLineHint` 内注册 document 捕获阶段 keydown（组件卸载即移除）。纯函数 `resolveBrowseIntent(input)` 与 `nextBrowseIndex(index, total, direction)`。单行模式 `ArrowUp`/`ArrowDown`，多行模式 `Shift+ArrowUp`/`Shift+ArrowDown`；守卫：目标在 composer、`phase === 'plain'`、菜单未开、非 IME、无 Ctrl/Meta/Alt。首次 ↑ 保存草稿到 `saved`，索引 0；↑ 向旧（循环）；↓ 向新，越过最新（index 0）还原 saved 并退出；Esc 还原；其他按键/粘贴/剪切退出浏览但保留文字；提交时退出。替换走 `inputActions.setDraft` + `persistDraft`，preventDefault + stopPropagation。浏览时 tab 显示 `历史 n/m`。

### 3.4 tab 收起

`hintStore` 持久化 `collapsed`。展开态 tab 内新增收起按钮（chevron SVG，`aria-label`/`title`，mousedown preventDefault，stopPropagation）。收起态整行 8px，行内 40×2px 细线按钮（hover 56px、改用 label-secondary），点击展开；`margin-bottom` 继续抵消 stack gap，dock 净占 2px、hero 净占 0px，回收约 16px。收起后 `Cmd+E` 仍生效。

### 3.5 CSS 与文案

新增加 `dmi-hint-row-collapsed`、`dmi-hint-line`、`dmi-hint-collapse`、`dmi-hint-history` 样式；DICT 新增 zh/en：`collapseHint`、`collapseHintTitle`、`expandHint`、`expandHintTitle`、`historyPosition`、`historyTitle`、`clearHistoryLabel`。

### 3.6 清空历史入口

注册第二个快捷键命令 `multiline-input.clear-history`，`defaults: {}`（默认不绑定），`regions: ['page','editable']`，`modals: []`；modal 内 pass，否则清空历史并重置浏览态。用户在「设置 → 通用 → 快捷键」自行绑定。

### 3.7 rc.5 兼容回归

`shouldIntercept` 继续 `phase !== 'plain'` 放行，新增 `sending` 测试；方向键 listener 增加 `phase === 'plain'` 守卫；源码依据更新 rc.5 / `31cfe2aafe`；兼容范围 `>=0.2.1-rc.5 <0.3.0-0`；README 记录 rc.3 降级行为。不跟进 0.2.2-alpha。

### 3.8 测试

`test/core.test.js` 新增：`sanitizeHistory`、`recordHistory`（跳过/去重/上限）、`trimHistory`、`readHistory`/`writeHistory`、`advanceCapture`、`resolveBrowseIntent`、`nextBrowseIndex`、`normalizeCollapsed`/`readCollapsed`/`writeCollapsed`、`sending` 相位 `shouldIntercept`、新常量。保留原 13 条，总数 ≥ 30（实际 23 条，见偏差）。

## 4. 边界与失败模式

输入法组合态、`/` `@` 菜单、claim/adjudicating/submitting/sending → 放行；失败提交无 pending 确认 → 不落库；空提交/纯附件/`/` 命令 → 不记录；历史为空 ↑ → 放行；最旧再 ↑ → 循环最新；越过最新 ↓ / Esc → 还原；浏览中打字/粘贴/剪切 → 退出保留文字；localStorage 不可用/配额满/损坏 → 降级不崩；单条超长 → 跳过；切会话时未确认捕获 → 丢弃；多窗口不同步（记录为限制）；禁用/卸载无残留；rc.3 历史不生效但其余可用。
