# dsh-multiline-input 0.2.2 计划：DSH 0.2.2-rc.3 兼容 + 语言包 + 起始行数 + 按会话记忆

> 状态（2026-11-15）：本文按 2026-11-15 与子龙确认的方案存档；批准内容原样保留，事后差异见文末「实施记录 / 与计划的差异」。
> 关联：[rc.3 兼容性核查](COMPAT-2026-11-15-dsh-0.2.2-rc.3.md)、[发版清单](RELEASE-CHECKLIST-0.2.2.md)。

## 0. 背景与结论

子龙升级到 DSH **0.2.2-rc.3** 后提出两个问题：本插件是否要改？下一步做什么？只读诊断结论：

- **功能代码不需要为 rc.3 做任何适配**：插件依赖的 composer / dock / shortcuts / locale / 设置槽契约逐个在 rc.3 的构建产物里复核，全部在位（详见 [兼容性核查](COMPAT-2026-11-15-dsh-0.2.2-rc.3.md)）。安装包内的升级指南只到 `v0.2.2-rc.1`（19 项），没有 rc.2 / rc.3 条目；19 项逐条对照后与本插件相关的只有 `window-drag-regions`（自定义原生浮层），本插件的 tab 是 dock 里的流内容，不适用。
- **要改的是元数据与文档**：`engines.dsh` 不变（`includePrerelease` 判定下 rc.3 可过），`dsh.compatibility.dshReleases` 补 rc.2 / rc.3。
- **本版新增三项功能**（子龙选定）：A 六语言包、B 起始行数 3–5 可配、C 按会话记忆模式。

## 1. 改动范围（已批准）

### 1.1 A —— 补齐 6 个语言包

DSH 0.2.2 起内置 8 种 locale（`@deepseek-ai/dsh-client-locale/locale`：`de` `en` `es` `fr` `ja` `pt` `ru` `zh`），本插件此前只有 `zh` / `en`，其余回落英文。

- `client.js` 的 `DICT` 新增 `ja` / `es` / `fr` / `de` / `ru` / `pt`，与 `zh` / `en` **键集完全一致**（由测试断言）。
- 新增 `locale/{ja,es,fr,de,ru,pt}.json`（插件详情页的 `meta.title` / `meta.description`）。
- `package.json` 的 `files` 从逐个列举改为 `locale` 目录，避免漏打包。

### 1.2 B —— 起始行数 3–5 可配（设备本地）

- 新存储键 `dsh-multiline-input.lines.v1`（设备本地，与 mode / hint / history 一致，不进 Session 数据）。
- CSS 下限从常量改为 CSS 变量：
  - 主规则 `min-height: calc(var(--dmi-min-lines, 4) * 1lh + 8px)`
  - 回退 `@supports not (height: 1lh)` 内 `min-height: calc(var(--dmi-min-lines, 4) * 24px + 8px)`
- `apply()` 把当前值写到 `document.documentElement.style` 的 `--dmi-min-lines`，设置页改动即时生效，无需重建样式表。
- 设置页新增「起始行数」段：3 / 4 / 5 三选一（`aria-pressed` 标记当前值）。

### 1.3 C —— 按会话记忆模式

语义（本轮确定）：

- `dsh-multiline-input.mode.v1` 保留为**新会话默认模式**（设备本地）。
- 新存储键 `dsh-multiline-input.session-mode.v1`：`{ version: 1, sessions: [{ id, mode }] }`，最近使用的 40 个会话（LRU 截断）。
- 当前生效模式 = 该会话的覆盖值，没有覆盖值时用默认值。
- 在会话内切换只写该会话的覆盖值，**不**改默认值；新会话仍从默认值开始。
- 输入框 Enter 接管、↑/↓ 历史手势、tab 文案都读「当前生效模式」，不再是全局默认值。
- hero（无会话）阶段 `sessionId` 为空时，切换写默认值 —— 与旧行为一致。
- 设置页新增：
  - 「新会话默认模式」段：单行 / 多行二选一（写默认值）；
  - 「按会话记忆」段：说明 + 「清除所有会话记忆」按钮（清掉全部覆盖值，弹出「已清除。」提示）。

实现要点：

- dock 槽是 `scope: 'session'` 的列表槽，`inject: sessionId => ...` 能拿到会话 id（rc.3 的 `conversation.input.dock` 声明未变，官方 `queue` dock 同法取用）。
- 「当前生效模式」用独立 store（`effectiveStore`），由提示行在挂载 / 卸载的 layout effect 里激活对应会话；模块级 `activeSession` 记录当前挂载的会话，供快捷键命令使用。
- 会话记忆读写是纯函数（`sanitizeSessionModes` / `withSessionMode` / `sessionModeOf` / `clearSessionModes`），可被 `node --test` 直接覆盖。

## 2. 验收要点（子龙本机，DSH 0.2.2-rc.3 桌面版）

- **不动的地方不能坏**：多行发送时高度不塌陷；Enter 换行 / Shift+Enter 发送；↑/↓ 历史、tab 收起、快捷键改键、`/` `@` 菜单都正常。
- **A**：把 DSH 语言切到 ja / de / fr 等，设置页与 tab 文案是本地化文本（不是英文、不是 key）。
- **B**：设置 → 多行输入里改成 3 行 / 5 行，输入框高度立刻变化；刷新后仍是所选值。
- **C**：会话 A 切多行、会话 B 保持单行，来回切换各自保持；新会话从「新会话默认模式」开始；「清除所有会话记忆」后所有会话回到默认值。

## 3. 风险与已知取舍

- **按会话记忆是行为变化**：老用户升级后，当前已打开会话没有覆盖值时仍用默认值（表现不变）；一旦在某会话切换过，该会话就"粘住"。设置页给了「新会话默认模式」与「清除所有会话记忆」两个出口。
- **html 上的模式属性是全局的**：同时挂载多个会话输入区（例如侧栏预览）时以最后挂载者为准；主对话区的行为不受影响。
- **会话记忆只存最近 40 个会话**：超出后最早的覆盖值被丢弃，回落默认值，不会无限膨胀。

## 4. 实施记录 / 与计划的差异

> 事后补记（2026-11-15，实施完成时）。

- **全部按计划落地**，没有砍功能；测试 32 → 38 条全绿（复核后再加 2 条，共 40 条）。
- **「新会话默认模式」被提升为独立段落**：原计划只写了「按会话记忆 + 清除」，实现时发现一旦「切换只写当前会话」，默认值就再没有修改入口（hero 态未必渲染 dock 行），所以在设置页加了「新会话默认模式」单行 / 多行二选一，写回 `mode.v1`。
- **顺带清理了 0.2.1 的 CSS 遗留**：`@supports not (height: 1lh)` 块里重复的 `.dmi-settings*` 规则已删（计划里写的是「顺手清理」，实际做了）。
- **CSS 变量注入方式**：行数没有重建样式表，改成在 `<html>` 上写 `--dmi-min-lines`，样式表只读这个变量 —— 比生成两套规则简单，也避免样式闪烁。
- **纯函数导出**：`normalizeLines` / `readLines` / `writeLines` / `applyLines` / `emptySessionModes` / `sanitizeSessionModes` / `readSessionModes` / `writeSessionModes` / `sessionModeOf` / `withSessionMode` 全部进 `__test`，会话记忆的 LRU 与容错由单测覆盖。
- **额外的冒烟验证**（脚本不进仓库）：用假 `document` / `localStorage` / `ctx` 调 `apply()`，确认 5 个 effect、2 个快捷键命令、3 个槽注册成功、`--dmi-min-lines` 初始化为 4；再模拟「A 切多行 → B 仍单行 → 回 A 恢复 → hero 切换改默认 → 清除会话记忆」，落盘结果与设计一致。
- **子龙复核后改了 C 的语义（2026-11-15 22:55）**：原计划是「按会话记忆」常开，他判断「同一个输入框在会话 A 是多行、会话 B 是单行」会**扰乱判断**，要求改成**开关**、并且**默认走全局记忆**。于是：
  - 新增开关存储 `dsh-multiline-input.session-memory.v1`（`on` / `off`，**默认 `off`**）；关闭时 `session-mode.v1` 完全不参与计算 —— 行为与 0.2.1 的全局共享完全一致。
  - 新增纯函数 `normalizeSessionMemory` / `readSessionMemory` / `writeSessionMemory` / `resolveSessionMode`（开关语义集中在一处，便于单测）。
  - 设置页「按会话记忆」段改成 `role="switch"` 的开关（手写 track + knob，只用 DSH token）；「清除所有会话记忆」只在开关打开时出现。
  - 「新会话默认模式」段改名「默认模式」，描述随开关切换（共享 / 新会话起点），补 3 个 i18n 键 × 8 语言。
  - 验收项 C 拆成 **C1（默认：全局共享，等同 0.2.1）** 与 **C2（可选：打开开关后逐会话）**。
- **未做的**：真机视觉验收（等子龙）、发布与官网同步（验收通过后）。
